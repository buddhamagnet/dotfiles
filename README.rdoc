== Installation

  git clone https://github.com/buddhamagnet/dotfiles ~/Code/dotfiles
  cd ~/Code/dotfiles
  cargo run --release

Add --dry-run to preview what would be linked without touching anything:

  cargo run --release -- --dry-run

== What it does

+dotfiles-install+ (src/main.rs) symlinks the files in this repo into
$HOME (e.g. zshrc -> ~/.zshrc). If a target already exists and differs,
you'll be prompted to overwrite (y/n/a/q, same as the old rake task);
anything overwritten is moved to ~/.dotfiles-backup/ first, not deleted.

It then installs what the dotfiles depend on but can't symlink, skipping
anything already present: the JetBrains Mono font, Nushell, and Carapace
via Homebrew, Starship via its official installer script, and the
catppuccin tmux plugin, git-cloned at a pinned tag into
~/.config/tmux/plugins/catppuccin/tmux. tmux.conf +run+s that plugin, so
tmux errors on every start without it. To move to a newer catppuccin,
bump +TMUX_PLUGIN_TAG+ in src/main.rs and re-clone.

== Features

zshrc is customised for oh-my-zsh; gitconfig, tmux.conf, gdbinit, ghci,
and a Leiningen profile are all included and kept in sync with what
actually runs day to day.
